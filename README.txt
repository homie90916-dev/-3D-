解放的哈爾巴斯：FINAL 9.0 — 原版視覺重整測試版
=================================================

本版依照使用者提供的天堂 M 實機錄影作為視覺參考，第一步先將原本單調的程式生成地板，替換為高細節暗黑王族陵墓戰場背景，加入紅金色地面紋章、紫色魔力裂紋、火盆、石柱與環境微粒。

本版仍是獨立製作的網頁原型，並非官方天堂 M 客戶端，也不包含從官方遊戲擷取的模型或素材。

【本版內容】
- 高細節古代王族陵墓戰場背景
- 保留既有哈爾巴斯角色動畫圖集（紅披風、無龍翼）
- 保留三種敵人、怪物追擊、刷新、血條與傷害數字
- 保留普通攻擊、自動攻擊、技能範圍特效、MP 回復
- 保留 HP／MP／EXP、升級選擇、波次、擊殺統計
- 保留 iPhone Safari 虛擬搖桿與 PC WASD／方向鍵操作
- 保留小地圖、技能快捷列、藥水與目標鎖定

【檔案】
index.html：遊戲入口
style.css：介面樣式
main.js：遊戲邏輯與繪圖
arena_ancient_ruins.png：高細節戰場背景
halpas_animated_sprites.png：角色動畫圖集
halpas_directional_run.png：八方向跑步圖集
halpas_original_cutout.png：角色參考素材

【iPhone Safari 更新】
1. 解壓縮 ZIP。
2. 將 index.html、style.css、main.js 與所有 PNG 素材一併上傳到 GitHub Pages 專案根目錄。
3. 覆蓋同名檔案並 Commit。
4. 部署完成後重新整理 Safari，必要時使用無痕視窗測試快取。

操作：左側搖桿移動；右側普通攻擊、技能、紫炎斬、生命藥水；AUTO 開關自動攻擊。
PC：WASD／方向鍵移動，空白鍵攻擊，Q 施放技能。
