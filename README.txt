解放的哈爾巴斯 FINAL 8.1
==========================

本版以 FINAL 8.1 與你 2026-11-19 的實際測試錄影為基礎，修正攻擊動畫優先順序並調整人物比例。

本版重點
--------
- 天堂 M 風格 HUD：角色資訊、HP／MP／EXP、BUFF、迷你地圖、波次／擊殺資訊與技能快捷列
- 暗黑地下城風格戰場：深色破損石地、火盆、殘柱、旗幟與暗角光影
- 哈爾巴斯：保留 FINAL 7.0 的透明角色動畫素材、紅披風、金色角盔、黑金重甲與紫色武器
- 角色八方向跑步逐格動畫，依照移動方向轉身
- 人物顯示比例縮小約 22%，讓人物與怪物更協調
- 修正普通攻擊動畫：攻擊時優先顯示原始揮刀連擊圖集，不再被跑步圖覆蓋
- 揮刀動作包含舉刀、斬擊、收勢三段，並保留紫色斬擊軌跡
- 保留角色攻擊、爆炎、受擊、死亡、披風與重量感動態
- 怪物種類增加：原有魔物、骷髏與重裝敵人
- 紫色範圍爆炎加入升起的能量柱、魔法陣、粒子與傷害數字
- 迷你地圖、目標方向鎖定、生命藥水快捷鍵
- 保留自動攻擊、怪物追擊、波次、擊殺、升級、死亡與重新開始

玩法
----
iPhone Safari：
- 左下虛擬搖桿移動
- 普通攻擊、哈爾巴斯爆炎、紫炎斬
- AUTO 開／關
- ◎ 鎖定最近怪物方向
- 生命藥水快捷鍵恢復 35 HP

Windows／桌面：
- WASD 或方向鍵移動
- 空白鍵普通攻擊
- Q 施放哈爾巴斯爆炎

GitHub 更新方式（iPhone）
-------------------------
1. 下載並解壓縮 ZIP。
2. 開啟 GitHub 儲存庫。
3. 選 Add file -> Upload files。
4. 將資料夾內「全部六個網站檔案」上傳到儲存庫根目錄，覆蓋同名檔案（包含三個 PNG 動畫素材，不能只上傳 HTML／CSS／JS）。
5. Commit changes。
6. 等待 GitHub Actions 的 Pages 部署成功。
7. Safari 開啟網站並重新整理；如仍是舊版，網址後加 ?v=final-8-1 強制更新快取。

重要說明
--------
本版使用原創重繪的方向跑步與動作精靈圖，並非天堂 M 官方遊戲素材或官方角色模型。視覺構圖參考你提供的兩張圖片；要達到與官方遊戲完全一致，仍需合法取得原版遊戲角色與場景資產。
