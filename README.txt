解放的哈爾巴斯 FINAL 5.1

以 FINAL 5.0 完整遊戲為基礎，保留原有 iPhone Safari 介面、搖桿、怪物追擊、自動攻擊、普通攻擊、爆炎技能、HP/MP/EXP、波次及升級選擇。

FINAL 5.1 動作精修：
- 待機：四格慢速循環，增加細微身體起伏。
- 走路：四格步伐循環加快並增加上下步伐起伏。
- 普通攻擊：加入前置、舉刀、命中、收招四階段；傷害判定延後到揮擊命中時，並加入短暫畫面震動及斬擊效果。
- 哈爾巴斯爆炎：四階段蓄力、能量環繞、爆發、餘焰；增加短暫戰場震動。
- HUD 不隨戰場震動，手機操作區維持穩定。
- 更新所有快取版本號，避免 Safari 沿用舊版 JS / CSS / 圖片。

部署：
1. 解壓縮 ZIP。
2. GitHub 儲存庫 -> Add file -> Upload files。
3. 上傳以上六個檔案並覆蓋同名檔案。
4. Commit changes，等待 GitHub Pages workflow 成功。
5. 關閉舊分頁後重新開啟：
   https://homie90916-dev.github.io/-3D-/?v=final-5-1
