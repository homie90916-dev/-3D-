解放的哈爾巴斯：FINAL 10.0
============================

本版以 FINAL 9.0 可玩原型為底，進行第一輪角色與戰鬥視覺重製。

【本版重點】
- 換上高細節黑紫金盔甲、金色角盔、紫色巨劍與紅披風角色圖集。
- 新角色圖集包含待機、動作、劍擊與受擊姿勢；移動仍使用既有八方向跑步圖集。
- 玩家角色畫面比例提高，戰鬥姿勢與受擊表現更新。
- 怪物擴充為骷髏、食屍鬼、重裝騎士、死靈法師、深淵巨獸五種。
- 巨獸體型、法師法杖與魔法光點、各怪物血條及小地圖標記有所區分。
- 強化紫色劍氣、多層斬擊光弧、爆炎範圍與畫面震動。
- 怪物刷新上限隨波次逐步增加，並設有 18 隻上限以顧及手機效能。

【保留玩法】
- iPhone Safari 虛擬搖桿與 PC WASD／方向鍵
- 自動攻擊、普通攻擊、技能、生命藥水與鎖定目標
- 怪物追擊、擊殺、經驗值、升級選擇、波次與死亡重開

【檔案】
index.html：遊戲入口
style.css：介面樣式
main.js：遊戲邏輯、繪圖與戰鬥
arena_ancient_ruins.png：戰場背景
halpas_animated_sprites_v10.png：高細節主角四乘四動畫圖集
halpas_directional_run.png：八方向跑步圖集

【iPhone Safari 更新】
1. 解壓縮 ZIP。
2. 將 index.html、style.css、main.js 與 PNG 素材上傳到 GitHub 儲存庫根目錄並覆蓋同名檔案；新增 halpas_animated_sprites_v10.png。
3. Commit changes，等待 GitHub Pages 部署完成。
4. Safari 開啟：https://homie90916-dev.github.io/-3D-/?v=10.0

注意：本版為原創重製素材與網頁遊戲原型，並非官方天堂 M 模型或官方客戶端。請先在 iPhone Safari 實機測試效能與畫面。
