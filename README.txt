解放的哈爾巴斯 FINAL 5.0

本版以 FINAL 4.1 為基礎，保留原有遊戲玩法與 iPhone Safari 操作，並加入 4x4 角色逐格動畫圖集。

動畫圖集排列：
- 第 1 列：待機姿勢變化
- 第 2 列：走路循環
- 第 3 列：近戰攻擊
- 第 4 列：哈爾巴斯爆炎蓄力與爆發

主角會依照移動、普通攻擊、技能狀態切換動畫影格，不再只讓一張靜態圖片滑動。

重要說明：動畫影格是根據使用者提供的天堂 M 官方外觀截圖及實機影片，重新製作的 2D 動畫詮釋；並非從影片精確擷取的官方遊戲影格，也不是官方 3D 模型。原始官方圖片仍保留在 halpas_original_cutout.png 作為參考素材。

檔案：
- index.html
- main.js
- style.css
- halpas_animated_sprites.png（遊戲實際使用的逐格動畫）
- halpas_original_cutout.png（原始參考圖，保留）
- README.txt

iPhone / GitHub Pages 更新：
1. 解壓縮 ZIP。
2. 開啟 GitHub 儲存庫的 Code 頁面。
3. Add file -> Upload files。
4. 上傳以上六個檔案並覆蓋同名舊檔。
5. Commit changes。
6. 等待 GitHub Actions 的 Pages 部署成功。
7. 關閉舊遊戲分頁，再用 Safari 開啟新版網址。
