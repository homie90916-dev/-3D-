解放的哈爾巴斯：FINAL 8.2
==========================

本版以使用者實際測試的 FINAL 8.1 為基礎更新。

本次重點：
- 修正待機：停止移動時改用角色精靈圖集的待機列，四格緩慢循環，呈現呼吸與披風微動感。
- 保留八方向跑步圖集與普通攻擊／爆炎動畫。
- 玩家顯示比例調整為較和諧的戰場比例。
- 怪物重新繪製：增加盔甲層次、骨骼細節、角、眼部發光、胸甲及血條。
- 場景增加遺跡、火盆與石柱氣氛元素。
- 保留 iPhone Safari 虛擬搖桿、自動攻擊、普通攻擊、技能、升級、怪物追擊及波次。

注意：
這是原創 2D／2.5D 網頁遊戲原型，採用目前專案內的角色圖集與自行繪製的場景／怪物。
它不是天堂M官方遊戲、官方模型或官方素材，無法宣稱達到官方原版還原度。

部署：
1. 解壓縮 ZIP。
2. 將 index.html、style.css、main.js 與三張 PNG 素材上傳到 GitHub Pages 專案根目錄，覆蓋同名檔案。
3. Commit changes，等待部署完成。
4. 使用網址後綴 ?v=final-8-2 重新載入，避免舊快取。
