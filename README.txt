解放的哈爾巴斯：王族陵墓戰記
================================

本版本以使用者提供的實測錄影與既有可玩原型為參考，進行完整的 2.5D 戰場整合。

內容：
- 斜俯視古代王族陵墓戰場
- 哈爾巴斯角色：黑紫金盔甲、金色角盔、紫色巨劍、紅披風，不加龍翼
- 新增亡靈戰士逐格圖集：待機、移動、攻擊、死亡
- 怪物分為骷髏、食屍鬼、重裝騎士、死靈法師與深淵巨獸（使用同一骨架圖集的材質變化與比例差異）
- 怪物追擊、攻擊動畫、受擊閃光、血條與死亡動畫
- 紫色範圍爆炎、劍氣、暴擊文字、粒子與畫面震動
- HP/MP/EXP、等級提升、波次、擊殺、小地圖、AUTO、自動攻擊、虛擬搖桿
- PC：WASD/方向鍵移動、空白鍵攻擊、Q 施放技能

安裝：將本資料夾全部檔案上傳到 GitHub Pages 儲存庫根目錄，覆蓋同名檔案並新增 halpas_enemy_sprites.png。

注意：這是原創 2D/2.5D 網頁遊戲，不是官方天堂 M 客戶端，也不包含官方原始模型或素材。iPhone Safari 實機效能仍需在目標裝置驗證。
