iPhone GitHub 更新步驟：
1. 在 iPhone「檔案」App 下載並解壓縮本 ZIP。
2. 開啟 GitHub 儲存庫 https://github.com/homie90916-dev/-3D-
3. Add file -> Upload files。
4. 上傳以上四個檔案，覆蓋儲存庫中的同名檔案。
5. Commit changes，等待 Actions 的 pages build and deployment 顯示綠色勾勾。
6. 開啟 https://homie90916-dev.github.io/-3D-/?v=final-3

注意：角色 PNG 是依使用者提供的低解析度卡片圖片去背取得，並非官方高解析度模型。
這是正面 2D 圖片角色；移動時保留正面圖，不會像 3D 模型一樣自由轉身。
