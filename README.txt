解放的哈爾巴斯 FINAL 11.0｜完整戰場版
========================================

本版以 FINAL 10.0 為基礎，針對使用者實測影片中的主要問題進行整體調整。

本次重點
- 初始怪物改為在玩家周圍可視距離內生成，不再大量出生於螢幕外。
- 初始戰場怪物數增加，持續刷新上限隨波次提升。
- 怪物血條常駐顯示，受擊時更容易辨識目標狀態。
- 怪物攻擊加入前衝動態，戰鬥畫面更容易讀懂。
- 玩家角色比例略為放大，保留紅披風、金角盔、黑紫金盔甲、紫色巨劍，不加龍翼。
- 加強鏡頭跟隨位移，維持既有地圖、HUD、技能、升級與手機操作。

檔案
- index.html：遊戲入口
- style.css：介面樣式
- main.js：遊戲核心與戰鬥邏輯
- arena_ancient_ruins.png：陵墓戰場背景
- halpas_animated_sprites_v10.png：哈爾巴斯動畫圖集
- halpas_directional_run.png：八方向跑步圖集

部署
1. 解壓縮 ZIP。
2. 將所有檔案上傳到 GitHub Pages 儲存庫根目錄並覆蓋同名檔案。
3. Commit changes，等待 GitHub Pages 部署成功。
4. Safari 開啟 https://homie90916-dev.github.io/-3D-/?v=11.0

操作
- 手機：左下虛擬搖桿移動；右下普通攻擊、技能、藥水與 AUTO。
- PC：WASD／方向鍵移動，空白鍵攻擊，Q 施放技能。

技術說明
本版是以原創程式、繪製怪物和可用圖集製作的 2D／2.5D 單機原型，並非官方天堂 M 客戶端或官方模型的直接移植。請先在 iPhone Safari 實測；不同裝置效能可能不同。
