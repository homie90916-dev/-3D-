解放的哈爾巴斯 FINAL 4.1

本版以 FINAL 4.0 為基礎，保留原有戰鬥系統、怪物、搖桿、普通攻擊、自動攻擊、哈爾巴斯爆炎、升級選技能及 iPhone Safari 版面。

本次修正：
- 主角官方截圖擷取素材縮小至前一版約 59% 的顯示尺寸。
- 保持圖片底部與藍色定位光圈對齊，避免頭部被上方 HUD 遮住。
- 降低額外紫金色背景光暈，讓角色原圖更清楚。
- 更新圖片、CSS、JS 快取版本號，避免 Safari 繼續使用舊檔。

檔案：
- index.html
- main.js
- style.css
- halpas_original_cutout.png

iPhone / GitHub Pages 更新：
1. 解壓縮 ZIP。
2. 到 GitHub 儲存庫的 Code 頁面。
3. Add file -> Upload files。
4. 上傳以上四個檔案並覆蓋同名舊檔。
5. Commit changes。
6. 等待 GitHub Actions 的 Pages 部署成功。
7. 用 Safari 開啟網站並重新整理；必要時關閉舊分頁後重新開啟。

注意：素材來自使用者提供的官方網站截圖，解析度受來源截圖限制；這不是官方 3D 模型或逐格動畫。
